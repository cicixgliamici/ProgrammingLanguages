# Programming Languages Reference & Practice

This repository is inspired by [quickref.me](https://quickref.me/) and serves as a comprehensive collection of programming concepts, data structures, algorithms, and mini-projects. It's designed to help developers prepare for technical interviews and enhance their programming skills through practical examples.

## Repository Structure

The repository is organized by programming languages, with each language directory containing:
- Basic concepts and syntax
- Data structures implementations
- Common algorithms
- Mini-projects
- Best practices and patterns

### Available Languages

- [C Programming](./C/) - Low-level programming concepts, memory management, and system programming
- [Java](./Java/) - Object-oriented programming, Spring Framework, and enterprise patterns

## How to Use This Repository

1. **Study**: Each implementation comes with detailed comments and explanations
2. **Practice**: Try to implement the concepts yourself before looking at the solutions
3. **Experiment**: Modify the code to understand different scenarios and edge cases
4. **Contribute**: Feel free to add your own implementations or improve existing ones
